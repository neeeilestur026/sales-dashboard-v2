One inclusion per line — each prints as its own bullet under this item's description. Wrap a line in **asterisks** to make it a sub-heading (e.g. **Standard Accessories**); it stays with the line beneath it so a page break cannot separate them. Add as many lines as you like — they flow onto the next page rather than being cut. A single line longer than 1,200 characters is shortened on the document with a “…”, and the quotation refuses to save if all its scope text together passes 45,000 characters.
