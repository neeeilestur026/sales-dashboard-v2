Product Finder — Data Admin

The catalog lives in dashboard/data/*.json — edit those files to update it permanently. Uploading here stages a replacement on THIS device only (stored in the browser), useful for testing a new catalog before committing it. Unverified rows are sample data and are never shown as safe answers.

Data health

Schema + cross-file reference checks (broken pairs_with / wrench_id / our_id, torque outside a wrench's range, duplicate ids…). Uploads with errors are rejected before staging.

Miss log (pf_misses)

What customers typed that matched NO category — grow synonyms.json from this weekly. The CSV is the training dataset.
